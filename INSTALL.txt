ETS2LA 简体中文补全（ZhHansFix）安装说明
========================================

一、安装（推荐：用安装脚本，会自动登记到 ETS2LA 的插件清单）
----------------------------------------------------------
1. 解压本压缩包。
2. 右键 install.ps1 -> “使用 PowerShell 运行”；或在 PowerShell 中执行：
     powershell -ExecutionPolicy Bypass -File install.ps1
   脚本会做三件事：
     · 把 mldjy.zhhansfix 整个文件夹复制到 ETS2LA 的 Plugins 目录
     · 把插件登记到 %APPDATA%\ETS2LA\InstalledPluginManifest.json（先自动备份）
     · 清理旧版直接放在 Plugins\ 根目录里的两个 DLL
3. 重启 ETS2LA，在「插件管理」里启用「简体中文补全」。

二、手动安装（不使用脚本时）
--------------------------
1. 把整个 mldjy.zhhansfix 文件夹复制到：
     %LOCALAPPDATA%\ETS2LA\current\Plugins\
2. 用文本编辑器打开 %APPDATA%\ETS2LA\InstalledPluginManifest.json，
   在 "InstalledPlugins": [ ] 中增加一条（注意前一条后面要加逗号）：
     {
       "Id": "mldjy.zhhansfix",
       "Version": "1.0.0",
       "DllPath": "Plugins\\mldjy.zhhansfix\\ZhHansFix.dll",
       "Dependencies": [],
       "Type": 0
     }
3. 重启 ETS2LA 并启用插件。

   为什么要登记清单：ETS2LA 只会自动扫描 Plugins\ 根目录下的 DLL，
   子文件夹里的插件必须出现在上述清单中才会被加载。


三、启用 / 停用
---------------
在「插件管理」里勾选或取消勾选即可，瞬时生效。
  · 启用：界面立即变为中文
  · 停用：界面立即恢复英文


四、卸载
--------
运行 uninstall.ps1（会删除文件夹并移除清单条目），或手动删除：
  %LOCALAPPDATA%\ETS2LA\current\Plugins\mldjy.zhhansfix\  （整个文件夹）
以及清单里对应的那一条。


五、扩展词典
------------
词典是外置 JSON，改完存盘立即生效，不用重启程序：
  %APPDATA%\ETS2LA\zh-hans-fix.json
格式：
  {
    "Enable Lane Changes": "启用变道",
    "Path Length": "路径长度"
  }

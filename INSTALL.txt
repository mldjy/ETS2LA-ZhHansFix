ETS2LA 简体中文补全（ZhHansFix）安装说明
========================================

一、安装
--------
1. 把本压缩包里的三个文件复制到 ETS2LA 的插件目录：

   %LOCALAPPDATA%\ETS2LA\current\Plugins\

   三个文件是：
     ZhHansFix.dll
     ZhHansFix.Core.dll
     0Harmony.dll

   如果该目录里已经有 0Harmony.dll（别的插件装的），可以跳过这一个。

2. 重启 ETS2LA。

3. 打开「插件管理」，启用「简体中文补全」。
   （默认不启用；未启用时本插件不会改动任何界面文本。）

4. 确认语言为简体中文：设置 → 显示 → 语言 → 简体中文。

启用后，界面即为简体中文。


二、启用 / 停用
---------------
在「插件管理」里勾选或取消勾选即可，瞬时生效：
  - 启用：立即变为中文
  - 停用：立即恢复英文


三、卸载
--------
删除插件目录下的这三个文件后重启即可：
  ZhHansFix.dll
  ZhHansFix.Core.dll
  0Harmony.dll（若其它插件也用到，请不要删除）

另外，程序目录里会出现本插件同步的 Localization\zh_Hans.po
（程序目录与各插件目录下各一份），可一并删除。


四、扩展词典
------------
词典是外置 JSON，改完存盘立即生效，不用重启程序：

  %APPDATA%\ETS2LA\zh-hans-fix.json

格式：
  {
    "Enable Lane Changes": "启用变道",
    "Path Length": "路径长度"
  }

以冒号或空格结尾的键会按前缀匹配，以空格开头的键会按后缀匹配。


五、注意事项
------------
- 启动阶段会预挂补丁，约 8 秒。这段时间与程序解析地图数据同时进行，
  不影响使用；此后启用/停用都是瞬时的。
- 仅适用于 Windows 版 ETS2LA。
- 第三方社区插件，与 ETS2LA 官方无隶属关系。
